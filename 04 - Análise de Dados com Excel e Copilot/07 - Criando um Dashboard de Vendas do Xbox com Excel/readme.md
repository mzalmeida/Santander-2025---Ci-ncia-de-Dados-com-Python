# 📊 Dashboard de Vendas - Xbox Game Pass

Este projeto apresenta um **dashboard interativo desenvolvido no Excel** para análise das assinaturas do **Xbox Game Pass** e serviços relacionados.  
O objetivo é demonstrar habilidades em **visualização de dados, organização de métricas e storytelling com dashboards**, como parte da entrega do projeto da **Digital Innovation One (DIO)**.

---

## 🎯 Objetivo do Dashboard
- Consolidar informações de diferentes tipos de assinaturas.
- Facilitar a análise de desempenho por categoria (Mensal, Trimestral, Anual).
- Evidenciar os resultados de Season Pass específicos (EA Play e Minecraft).
- Permitir comparação entre usuários que possuem ou não o Xbox Game Pass.

---

## 🖼️ Estrutura do Dashboard

## **Filtro de Assinatura**
- Dropdown interativo para selecionar o tipo de assinatura:
  - **Mensal**
  - **Trimestral**
  - **Anual**

---

## 🛠️ Ferramentas Utilizadas
- **Microsoft Excel**
  - Tabelas dinâmicas
  - Gráficos de barras
  - Segmentação de dados (dropdown)
  - Formatação condicional

---

## 🚀 Como Utilizar
1. Abra o arquivo Excel do dashboard.
2. Utilize o menu suspenso para escolher o tipo de assinatura.
3. Analise os gráficos e caixas de métricas para identificar padrões e insights.
4. Explore os dados para embasar decisões estratégicas.

---

## 📌 Conclusão
Este dashboard demonstra como o **Excel pode ser usado como ferramenta poderosa de Business Intelligence (BI)**, permitindo transformar dados brutos em informações visuais claras e relevantes para análise de negócios.
