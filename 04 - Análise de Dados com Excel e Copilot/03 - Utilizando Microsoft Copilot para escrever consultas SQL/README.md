
# Banco de Dados — Currículos e Coleções (Oracle)

Projeto de banco de dados Oracle para gerenciar **currículos de usuários** e **conjuntos/coleções** (sets) aos quais esses currículos podem pertencer. Inclui **DDL das tabelas**, **chaves estrangeiras**, **views** para consulta consolidada, **exemplos de inserção** e **boas práticas**.

## Visão Geral
O projeto contém:
- **tbl_ccos**: tabela de coleções/sets (tabela pai).
- **tbl_cco_user**: tabela de currículos de usuários (tabela filha).
- **FK**: `tbl_cco_user.idcollectioncco` → `tbl_ccos.id`.
- **Views** para facilitar a consulta de dados consolidados.

---

## Requisitos
- **Banco de Dados**: Oracle Database 12c ou superior  
  (Uso de `GENERATED AS IDENTITY` para chaves primárias automáticas)
- Permissões para criar **tabelas**, **índices**, **views**, e opcionalmente **materialized views** e **triggers**.

---

## Modelo de Dados

**Tabelas principais**
- `tbl_ccos`
  - `id` (PK, identity)
  - `collection_set_name` (nome da coleção, único)
  - `total_cco_collection` (contador informativo de currículos)
- `tbl_cco_user`
  - `id` (PK, identity)
  - `nome` (obrigatório)
  - `sobre_mim` (CLOB)
  - `experiencia` (CLOB)
  - `habilidades` (CLOB)
  - `idiomas` (VARCHAR2(400))
  - `contato` (VARCHAR2(400))
  - `formacao` (CLOB)
  - `idcollectioncco` (FK para `tbl_ccos.id`, `ON DELETE SET NULL`)

**Relacionamento**
- 1 coleção (`tbl_ccos`) → N currículos (`tbl_cco_user`)

## Criação do Esquema (DDL)

> **Observação**: Nomes **sem espaços** são recomendados. Caso você tenha criado com espaços/aspas, adapte conforme necessário.

```sql
-- Tabela de coleções (pai)
CREATE TABLE tbl_ccos (
    id                    NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    collection_set_name   VARCHAR2(200)       NOT NULL,
    total_cco_collection  NUMBER              DEFAULT 0 NOT NULL,
    CONSTRAINT uq_tbl_ccos_name UNIQUE (collection_set_name),
    CONSTRAINT chk_tbl_ccos_total_nonneg CHECK (total_cco_collection >= 0)
);

COMMENT ON TABLE tbl_ccos IS 'Coleções de currículos (sets)';
COMMENT ON COLUMN tbl_ccos.collection_set_name IS 'Nome do conjunto/coleção';

CREATE INDEX idx_tbl_ccos_name ON tbl_ccos (collection_set_name);

-- Tabela de currículo (filha)
CREATE TABLE tbl_cco_user (
    id                   NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    nome                 VARCHAR2(200)      NOT NULL,
    sobre_mim            CLOB,
    experiencia          CLOB,
    habilidades          CLOB,
    idiomas              VARCHAR2(400),
    contato              VARCHAR2(400),
    formacao             CLOB,
    idcollectioncco      NUMBER,
    CONSTRAINT fk_tbl_cco_user_ccos
        FOREIGN KEY (idcollectioncco)
        REFERENCES tbl_ccos (id)
        ON DELETE SET NULL
);

COMMENT ON TABLE tbl_cco_user IS 'Tabela de currículos dos usuários';

CREATE INDEX idx_tbl_cco_user_nome ON tbl_cco_user (nome);
CREATE INDEX idx_tbl_cco_user_idcollectioncco ON tbl_cco_user (idcollectioncco);
```

## Exemplos de Inserção

### 1) Garantir coleções via *upsert* (MERGE)
```sql
MERGE INTO tbl_ccos c
USING (SELECT 'Tecnologia' AS collection_set_name FROM dual) s
ON (c.collection_set_name = s.collection_set_name)
WHEN NOT MATCHED THEN
  INSERT (collection_set_name, total_cco_collection)
  VALUES (s.collection_set_name, 0);

MERGE INTO tbl_ccos c
USING (SELECT 'Marketing' AS collection_set_name FROM dual) s
ON (c.collection_set_name = s.collection_set_name)
WHEN NOT MATCHED THEN
  INSERT (collection_set_name, total_cco_collection)
  VALUES (s.collection_set_name, 0);

COMMIT;
```

## Views

### View consolidada (recomendada)
```sql
CREATE OR REPLACE VIEW v_cco_users_full AS
SELECT
    u.id                   AS user_id,
    u.nome                 AS nome,
    u.sobre_mim            AS sobre_mim,
    u.experiencia          AS experiencia,
    u.habilidades          AS habilidades,
    u.idiomas              AS idiomas,
    u.contato              AS contato,
    u.formacao             AS formacao,
    u.idcollectioncco      AS collection_id,
    c.collection_set_name  AS collection_name,
    c.total_cco_collection AS collection_total
FROM tbl_cco_user u
LEFT JOIN tbl_ccos c ON c.id = u.idcollectioncco;
```

### View resumo por coleção
```sql
CREATE OR REPLACE VIEW v_cco_collection_summary AS
SELECT
    c.id                   AS collection_id,
    c.collection_set_name  AS collection_name,
    c.total_cco_collection AS total_in_tbl_ccos,
    COUNT(u.id)            AS total_linked_users
FROM tbl_ccos c
LEFT JOIN tbl_cco_user u ON u.idcollectioncco = c.id
GROUP BY c.id, c.collection_set_name, c.total_cco_collection;
```

## Triggers (Opcional)
Para manter `total_cco_collection` sincronizado automaticamente:

```sql
-- Incrementa ao inserir
CREATE OR REPLACE TRIGGER trg_cco_user_ins
AFTER INSERT ON tbl_cco_user
FOR EACH ROW
WHEN (NEW.idcollectioncco IS NOT NULL)
BEGIN
  UPDATE tbl_ccos
     SET total_cco_collection = NVL(total_cco_collection,0) + 1
   WHERE id = :NEW.idcollectioncco;
END;
/

-- Decrementa ao excluir
CREATE OR REPLACE TRIGGER trg_cco_user_del
AFTER DELETE ON tbl_cco_user
FOR EACH ROW
WHEN (OLD.idcollectioncco IS NOT NULL)
BEGIN
  UPDATE tbl_ccos
     SET total_cco_collection = GREATEST(NVL(total_cco_collection,0) - 1, 0)
   WHERE id = :OLD.idcollectioncco;
END;
/

-- Ajusta ao alterar a coleção
CREATE OR REPLACE TRIGGER trg_cco_user_upd
AFTER UPDATE OF idcollectioncco ON tbl_cco_user
FOR EACH ROW
BEGIN
  IF :OLD.idcollectioncco IS NOT NULL THEN
    UPDATE tbl_ccos
       SET total_cco_collection = GREATEST(NVL(total_cco_collection,0) - 1, 0)
     WHERE id = :OLD.idcollectioncco;
  END IF;

  IF :NEW.idcollectioncco IS NOT NULL THEN
    UPDATE tbl_ccos
       SET total_cco_collection = NVL(total_cco_collection,0) + 1
     WHERE id = :NEW.idcollectioncco;
  END IF;
END;
/
```

## Consultas Úteis

```sql

SELECT * FROM v_cco_users_full WHERE LOWER(nome) LIKE LOWER('%carlos%');

-- Resumo por coleção
```

## Erros Comuns e Soluções

### ORA-02291: restrição de integridade violada – chave mãe não localizada
Causa: `idcollectioncco` aponta para um `id` que **não existe** em `tbl_ccos`.  
**Soluções**:
- Insira as coleções primeiro (ou use `MERGE` do README).
- Não “chute” IDs; **busque o ID pelo nome** da coleção com `SELECT ... WHERE collection_set_name = '...'`.
- Verifique schema e constraints:
  ```sql
  SELECT id, collection_set_name FROM tbl_ccos;
  SELECT constraint_name, table_name FROM user_constraints WHERE table_name IN ('TBL_CCO_USER','TBL_CCOS');
  SELECT * FROM user_cons_columns WHERE constraint_name = 'FK_TBL_CCO_USER_CCOS';
  ```

### Nomes com espaços/aspas
Se tiver criado colunas com espaços, **sempre** use aspas e case exato:
```sql
SELECT "sobre mim" FROM "tbl_cco_user";
```
Recomendação: use `snake_case` sem acentos/espaços.

## Padrões de Nomeação
- Tabelas: `tbl_*`
- Views: `v_*`
- Materialized Views: `mv_*`
- Índices: `idx_*`
- Constraints: `pk_*`, `fk_*`, `uq_*`, `chk_*`
- Colunas: `snake_case`, sem espaços e sem acentos

## Checklist de Deploy
1. Criar tabelas e índices (`tbl_ccos`, `tbl_cco_user`).
2. (Opcional) Criar triggers de sincronização do total.
3. Criar views (`v_cco_users_full`, `v_cco_collection_summary`).

7. Conceder **grants** necessários.
