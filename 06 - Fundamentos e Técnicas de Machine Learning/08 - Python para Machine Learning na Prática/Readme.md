# Python para Machine Learning

Este repositório contém materiais introdutórios sobre **Python aplicado a Machine Learning**, baseados em conteúdos apresentados pelo Prof. Dr. Diego Bruno (Education Tech Lead na DIO e Doutor em Robótica e Machine Learning pelo ICMC-USP).

---

## 📚 Conteúdo

- **Programação básica com Python**
- **Instalação de dependências**
- **Principais bibliotecas de Machine Learning**
- **Ambientes de colaboração de código**
- **Configuração de GPU com CUDA**

---

## 🚀 Objetivo

Fornecer uma base sólida para quem deseja iniciar no mundo de **Machine Learning com Python**, cobrindo desde o primeiro programa até o uso de bibliotecas avançadas e ambientes de execução otimizados.

📊 Bibliotecas de ML
Principais bibliotecas utilizadas:
- NumPy → Operações matemáticas e vetoriais
- SciPy → Funções científicas e estatísticas
- Pandas → Manipulação e análise de dados
- Matplotlib → Visualização de dados
- Scikit-learn → Algoritmos de Machine Learning

🌐 Ambientes de Colaboração
- Google Colab → Execução em nuvem com GPU gratuita
- Jupyter Notebook → Ambiente interativo local
- VS Code → Editor com extensões para Python e ML
